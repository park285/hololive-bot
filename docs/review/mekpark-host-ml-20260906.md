## 데이터 확보

6개 탭, 총 13페이지가 모두 `exhausted=true`로 끝났다. 312개 영상의 공개 player metadata도
전부 성공했으며 제목과 정확한 시작/게시 시각을 저장했다. 수집 시각은
2026-09-06T06:05:59.525Z이다. 인증·쿠키·운영 helper는 사용하지 않았다.

| 채널 | 일반 영상 | streams | shorts | 고유 영상 |
|---|---:|---:|---:|---:|
| UNIT B | 7 | 97 | 17 | 121 |
| ACHRORA | 8 | 148 | 35 | 191 |

T01·AC01·V01: 기존 DB 제목 195건과 video_id로 합치면 316건이다. 공개 목록에서 121개를
추가했으며 DB에만 있는 네 건도 보존했다. DB 시각 조회는 `hololive-osaka`/`hololive`에서
`PGOPTIONS='-c default_transaction_read_only=on -c statement_timeout=10000'`을 적용하고
`SHOW transaction_read_only → on`을 확인한 뒤 두 채널만 최대 300행 조회했다.
공개 메타데이터로 DB의 비어 있던 게시 시각을 보완했으며 끝내 정확한 시각이 없는 두 건은
시간 분할 학습에서 제외했다. 상대적인 게시 시각이나 first_seen을 실제 게시 시각으로 대신 쓰지 않았다.

제목이 바뀐 경우 공개 제목을 현재 입력으로 쓰면서 원래 DB 제목도 남겼다. 예를 들어 DB의
`CF2KxTyJWVc`는 `?`였지만 공개 제목에는 히나미 이름이 있었다. 이 자료는 수집 시점의 제목
스냅샷이며 최초 알림 시점의 제목 기록은 아니다.

## 실험 구성

T02·AC02: scikit-learn 1.9.0의 문자 2~5-gram TF-IDF와 LogisticRegression을 사용했다.
유닛별로 세 멤버를 분류하며 원문과 이름 제거 변형을 각각 학습해 모델 네 개를 생성했다.
이름 제거 변형은 성명·이름 일부·개인 태그·시리즈 이름·남은 해시태그·이모지를 제거한다.
이는 문체/주제의 신호를 보는 합성 시험이며 실제 미상 제목의 분포를 그대로 재현하지 않는다.

2026-08-28 00:00 KST 이전의 221건을 학습, 이후 48건을 holdout으로 고정했다.
정규화한 동일 제목 그룹을 학습/holdout과 각 CV fold에서 분리했으며 영상 ID 중복도 검사했다.
어휘·IDF와 모델 학습은 각 fold의 학습 부분만 사용했다. C=0.5/2/8은 학습 자료의
3-fold StratifiedGroupKFold macro F1로 선택했고 동률이면 작은 C를 사용했다.
holdout 결과로 C나 점수 기준을 바꾸지 않았다.

| 유닛 | 학습 | holdout | 원문 C | 이름 제거 C |
|---|---:|---:|---:|---:|
| UNIT B | 83 | 15 | 0.5 | 0.5 |
| ACHRORA | 138 | 33 | 0.5 | 8.0 |

합방/다중 진행자와 정답 미상은 단독 진행자의 학습 정답으로 강제하지 않았다.
공개 설명으로 검토한 사례 11건도 평가 전용으로 고정했으며 학습에서 제외했다.

## 비교 결과

| 방식 | holdout 기대값과 일치 | 비율 | 여섯 멤버 macro F1 |
|---|---:|---:|---:|
| 현재 룰, 원문 | 48/48 | 100% | 1.0000 |
| 유닛별 최빈 멤버 | 24/48 | 50.0% | 0.2248 |
| 학습 모델, 원문 | 48/48 | 100% | 1.0000 |
| 학습 모델, 이름·태그·이모지 제거 | 31/48 | 64.6% | 0.5856 |

위 기대값은 기존 제목 검토와 새 공개 제목에 대한 룰의 약한 라벨을 포함한다.
따라서 룰과 모델의 100%가 실제 영상 출연자를 독립적으로 검수한 정확도는 아니다.
다른 영상 ID를 가진 clip과 원방송을 별도 연결하지 않았으므로 유사 콘텐츠의 상관성도 남아 있다.

점수 기준은 학습 fold 예측에서 정밀도 95% 이상이고 최소 10건을 수락하는 가장 낮은 후보를
선택했다. 점수 자체의 별도 확률 보정은 하지 않았다. 원문 모델은 두 유닛 모두 0.55를 선택해
holdout 37/48건을 수락했고 그 37건은 기대값과 일치했다. 이름 제거 모델은 ACHRORA 0.75,
UNIT B는 조건에 맞는 기준이 없어 전부 보류했다. 전체 holdout 중 수락은 6건이며 그 6건은 일치했다.

## 룰이 보류한 실제 제목

두 사례는 모델 예측 전에 공개 제목/설명을 검토해 평가 전용으로 두었다.

| 영상 | 확인 근거 | 원문 모델 1순위 | 점수 | 자동 수락 |
|---|---|---|---:|---|
| `C5GAyKlGcBo` | 제목에는 이름이 없지만 설명 첫 줄에 개별 태그 `#清澄ライラ`가 있음 | 라이라 | 0.3604 | 보류 |
| `OOfUWBQzqKk` | 제목의 주어 `ひなみ`와 설명의 `ゆいひな` | 히나미 | 0.4125 | 보류 |

후보는 두 건 모두 맞았지만 수가 적고 점수 기준 아래이므로 미상 제목의 자동 분류 성능이
검증됐다고 볼 수 없다. 이름 제거 모델은 두 사례에서 모두 다른 사람을 골랐다.

공개 메타데이터는 잘못된 정답을 만들지 않는 데에도 도움이 됐다. `Ie1e9qn5ZVk` 설명은
20시 사야나/21시 리라라/22시 히나미 릴레이이며 한 영상의 시작·종료가 세 구간을 모두
포함한다. 시작 시각의 사야나 한 명을 정답으로 세지 않았다. `1ryHugzR3_M`과
`T060Goa2yxg` 설명은 공통 멤버 소개만으로는 진행자를 확정할 수 없어 미상으로 남겼다.

이름 제거 모델은 `IeJfLC9XTG4`·`PtAy3wK_jGw`의 유닛 소개 티저에 히나미 점수 0.7709를
부여해 수락 기준을 넘겼다. 두 영상의 제목은 같으며 실제 개인 정답으로 채점하지 않았다.
단독 방송으로 분류할 수 없는 입력에서도 점수가 높아질 수 있다는 사례다.

## 재현과 검증

T03·AC03·V02·V03: Python 3.14.7, scikit-learn 1.9.0, NumPy 2.5.2, SciPy 1.18.1에서 실행했다.
PEP 723 script lock으로 전이 의존성을 고정했다. 서비스 의존성이나 버전은 바꾸지 않았다.

- `uv run --locked scripts/experiments/mekpark-host/experiment.py`: 모델 네 개와 결과 생성 성공.
- 같은 입력으로 별도 출력 디렉터리에 재실행한 결과 `results.json`, `dataset.json`이 byte 단위로 일치했다.
  결과의 모델 SHA-256도 일치했으며 각 모델은 저장 후 다시 읽어 확률 배열의 완전 일치를 확인했다.
- 저장된 모델의 `--predict` 실행으로 실제 제목에 대한 후보 조회도 확인했다.
- Go 기준선 및 CLI의 race 테스트, CLI의 golangci-lint와 NilAway가 통과했다.
- 수집 스크립트 Node 구문 검사, Python 구문 및 JSON 검사, 최종 diff·결정 카탈로그 검사를 수행했다.

입력/코드/모델 hash, 학습/holdout/fold의 영상 ID, 모든 오분류와 미상 제목 예측은 결과 JSON에
남겼다. 모델 파일과 입력 전처리 계약은 `.tmp/mekpark-host-ml/models/`에 있다.

## 활용 범위

실제 학습을 완료했고 원문 제목의 holdout 48건에서 약한 라벨을 모두 재현했다. 그러나 현재 시험에서는
룰 보류 항목을 자동 확정할 만큼의 추가 검증은 확보하지 못했다. 현재 룰은 유지하고 모델은
보류 사례의 검토 후보를 제시하는 용도로 사용하는 것이 적절하다. 더 많은 독립 검수 정답과
알림 시점 제목을 확보한 다음 별도 holdout으로 재평가해야 한다.
운영 연결·배포·실제 발송·DB 쓰기·Git commit/push는 수행하지 않았다. Fallback delta: none.
