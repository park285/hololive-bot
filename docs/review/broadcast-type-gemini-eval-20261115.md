# 방송 유형 Gemini 판정 표본 평가

미분류 방송 유형을 묻는 Gemini Decisions API(`gemini-decision-1`) 질문을 실제로 호출해 평가했다.
평가 결과로 질문 문구를 저장소 분류 체계에 맞추고, 판정을 쓰는 `confidence` 문턱을 0.3으로 정했다.
수치는 고정 표본에 대한 결과이며 운영에서 남은 미분류 방송의 정확도나 미분류 감소율이 아니다.

## 표본과 규칙

- 어려운 표본(hard): 한때 규칙이 미분류로 남겼다가 사람이 공개 자료로 검토한
  40건이다. 이 가운데 `reviewed_video` 11건이 제목 단서가
  없는 방송으로, 운영에서 Gemini가 받을 방송과 가장 닮았다.
- 회귀 코퍼스(corpus): `broadcast_type_corpus.json`의 기대 유형이다. `unknown`을 빼고 hard와 겹치는
  40건을 hard로 두어 139건이다. 정답이 제목·주제로 정한 것이라 hard보다 쉽다.
- 분할: `sha256(video_id)` 첫 바이트가 짝수면 dev(86건), 홀수면 holdout(93건)이다. 질문 문구는 dev
  결과만 보고 고쳤고, holdout은 마지막 질문으로 한 번만 돌렸다.
- 채점 제외: player가 멤버 전용이라고 확인한 hard 3건이다. 운영에서는 후보에서 빠지므로 정확도
  분모에 넣지 않았다. 썸네일이 404인 4건은 묻지 못했다.
- 문턱 규칙(결과를 보기 전에 정함): dev에서 `confidence ≥ t`인 답의 정밀도가 0.90 이상인 가장 낮은
  t를 0.30~0.95(0.05 간격)에서 고른다. holdout에서는 t를 다시 고르지 않는다.

입력은 운영 worker와 같은 코드(`decisionRequest`, 공용 client, 썸네일 downloader)로 만들었다.
같은 질문을 세 번 반복한 3건은 답과 확률이 모두 같았다.

## 질문 수정

| 회차 | 변경 | dev 정확도 | hard | 코퍼스 |
|---|---|---:|---:|---:|
| r0 | 처음 질문 | 72/82 | 12/15 | 60/67 |
| r1 | 저장소 규칙 순서의 우선순위(멤버 한정 → 동시시청 → 노래 → ASMR·경마 → 이벤트 → 뉴스 → 일반 형식)를 지시하고, 대회를 게임에서 이벤트로 옮기고, 선택지 설명에 일본어 표기를 더함 | 73/82 | 10/15 | 63/67 |
| r2 | ASMR을 ASMR이라고 내건 방송으로 좁히고, 이벤트의 `competition`을 `championship`으로, 기타에 대결형 버라이어티를 더함 | 78/82 | 13/15 | 65/67 |

r0의 오답은 제목의 멤버 한정 표기를 무시하고 형식을 고른 경우와, 주년·대회·凸待ち 방송을 잡담·게임으로
고른 경우였다. r1은 이를 고쳤지만 잠자기용 낭독·게임을 ASMR로, 대결 기획을 이벤트로 끌어갔다. 둘 다
규칙 JSON의 정의(ASMR은 `asmr` 표기, 이벤트는 대회·리그·결정전)와 어긋나 r2에서 좁혔다.

또 첫 실행 전에 요청마다 선택지 순서가 무작위로 바뀌는 것을 찾았다. `encoding/json/v2`가 map을
정렬하지 않아서였고, 공용 client가 `Deterministic(true)`로 직렬화하도록 고쳤다.

## 결과

dev에서 규칙대로 고른 문턱은 0.30이다(정밀도 0.951, 82건 모두 적용). holdout 결과는 다음과 같다.

| holdout | 정확도 | t=0.30 정밀도(적용) | t=0.50 정밀도(적용) |
|---|---:|---:|---:|
| 전체 | 83/90 | 83/89 (0.933) | 78/81 (0.963) |
| hard | 17/22 | 17/21 (0.810) | 14/17 (0.824) |
| hard 중 `reviewed_video` | 2/4 | | |
| 코퍼스 | 66/68 | | |

hard에서는 문턱을 0.75 아래로 올려도 정밀도가 거의 그대로이고 적용만 줄어서 0.3을 쓴다. r2 질문의
dev와 holdout을 합하면 hard 30/37, `reviewed_video` 5/8, 코퍼스 131/135다.

남은 오답의 대부분은 기타·기획(`other`) 방송이다. holdout에서 기타 11건 가운데 4건을 다른 유형으로
골랐다. 협업 상품 소개를 뉴스로(0.75), 촬영회를 이벤트로(0.72), 편지 쓰기 기획을 잡담으로(0.50),
holoX 기획을 게임으로(0.27) 골랐다. 나머지는 제목 단서가 없는 노래 방송(「腹痛カエル」, 잡담 0.36)과
Prisuners 잡담·Duolingo 영어 공부를 게임으로 고른 2건이다. 멤버 전용 3건은 잡담(0.72, 0.26)과
동시시청(0.51)으로 골라, player 확인 신호 없이 물으면 틀린다.

## 운영 미분류 적용

같은 질문(r2)을 운영 데이터의 실제 미분류 방송에 돌렸다. `hololive-seoul`의 `holo-postgres`/`hololive`를
`default_transaction_read_only=on`·`statement_timeout`·`lock_timeout`을 건 세션에서 읽었고(같은 세션에서
`transaction_read_only = on` 확인), 운영 DB에는 쓰지 않았다. 읽은 것은 최근 365일 `ENDED` 세션의 영상·채널 ID,
제목, 방송 이력 조회와 같은 주제·썸네일 보완, 멤버 전용 확인 여부다.

```text
captured_at=2026-11-14T15:32:17Z
```

| 구분 | 건수 |
|---|---:|
| 최근 365일 종료 방송 | 12,127 |
| 현재 규칙·검토로 미분류 | 739 (6.1%) |
| player 확인 멤버 전용(묻지 않음) | 43 |
| Gemini에 물은 방송 | 696 |
| 썸네일 404로 묻지 못함 | 15 |
| `confidence ≥ 0.3`으로 적용 | 668 |
| Gemini 적용 뒤 남는 미분류 | 71 (0.6%) |
| player 확인 멤버 전용을 멤버십으로 분류한 뒤 남는 미분류 | 28 (0.2%) |

문턱별 적용 수는 0.3에서 668, 0.5에서 530, 0.8에서 307이다. 0.3 이상 답의 유형은 게임 286, 잡담 136, 기타 122,
이벤트 40, 뉴스 38, 노래 27, 동시시청 15, ASMR 4건이다.

운영 미분류에는 정답이 없어, 0.3 이상 답에서 무작위로 뽑은 60건을 다른 판정자(Claude 하위 에이전트 3명, 20건씩)가
Gemini 답을 보지 않고 같은 근거(제목·주제·썸네일)와 같은 유형 정의로 분류해 비교했다. 사람 검토가 아니므로
정확도가 아니라 일치율이다.

| Gemini `confidence` | 일치 |
|---|---:|
| 0.8 이상 | 23/23 |
| 0.5 이상 0.8 미만 | 18/23 |
| 0.3 이상 0.5 미만 | 6/14 |
| 전체 | 47/60 |

판정자가 확신한다고 표시한 28건은 27건이 일치했다. 어긋난 13건 가운데 12건은 판정자도 확신하지 못한
방송이었고, 대부분 잡담과 기타(먹방·운동·문자 공부), 잡담과 이벤트(새 모델 공개를 흉내 낸 방송, 유닛 기획)
사이였다. 확신한 판정과 어긋난 1건은 3D 라이브 공연 영상을 Gemini가 이벤트(0.48)로, 판정자가 노래로 고른
경우다. 0.3~0.5 구간의 일치율이 낮지만 판정자도 확신하지 못한 방송이 대부분이고 표본이 14건뿐이라 문턱은
사전 규칙대로 0.3을 유지한다. 0.5로 올리면 운영 미분류는 209건(1.7%, 멤버 전용 분류 뒤 166건)으로 남고, 남는 답의 일치율은 표본에서
41/46이다.

player 확인 멤버 전용 신호는 최근 365일 691건에 1월부터 11월까지 고르게 있고, 사람이 검토한 멤버 전용 3건도 모두
표시되어 있다. 이 신호는 방송 중이 아니라 끝난 뒤의 다시보기 접근 범위다. 691건 모두 저장된 관측 시각이 방송 종료
뒤였고, 보존된 최근 이틀(2026-11-13~15)의 영상 관측 6,758건에서도 멤버 전용 관측 11건이 모두 방송 밖에서 나왔다.
공개로 방송한 뒤 다시보기만 멤버 전용으로 돌린 방송과 구별할 수 없다.

그래서 방송 이력은 규칙·검토가 미분류로 남긴 이 방송(43건)만 멤버십으로 분류한다. 제목만으로는 형식을 알 수 없고,
같은 player 확인으로 멤버십을 정한 영상별 검토(`raD2SDEffE8`)와 기준이 같다. 규칙이 이미 다른 유형으로 분류한 멤버
전용 방송 106건(잡담 34, 노래 22, 게임 17, 동시시청 17, ASMR 7, 기타 7, 이벤트 2)은 바꾸지 않았다. 여기에는
구독자 기념 노래 방송이나 참가형 게임 방송처럼 공개로 방송했을 가능성이 큰 제목이 섞여 있어, 제목·주제가 보여 주는
형식이 더 직접적인 근거다.

## 비용과 한도

입력은 요청당 약 1,150토큰(최대 1,184)이었고 응답 대기는 중앙값 0.7~0.9초였다. worker의 요청 간격 3초에서는
분당 약 2만 3천 토큰이다. 평가에서 호출한 요청은 표본 353건과 운영 미분류 681건이다.
